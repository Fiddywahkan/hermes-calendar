Privacy Policy

hermes-calendar — last updated September 2026

This policy describes how hermes-calendar ("the application") accesses, uses, stores, and shares information obtained from Google APIs. The application is a private, single-user automation tool operated by, and used exclusively by, its owner.

1. What Google data the application accesses

With the account owner's explicit authorization, the application requests one OAuth scope:

https://www.googleapis.com/auth/calendar

Through this scope it accesses:

  • Calendar events (titles, times, descriptions, locations, attendees) on the authorizing account's own calendars
  • Calendar settings and calendar lists belonging to the authorizing account

The application does not request or access Gmail, Drive, Contacts, or any other Google service or data type.

2. How the data is used

  • Solely to perform actions the account owner explicitly requests — creating, reading, updating, and deleting events on their own calendar
  • To answer the owner's questions about their own schedule
  • For no other purpose whatsoever

3. Where the data is stored

  • OAuth credentials (an access token and refresh token) are stored in a local file on the owner's own computer, protected by the operating system's file permissions.
  • Calendar data is processed locally on the owner's computer. It is not uploaded to, stored on, or processed by any third-party server, cloud service, or external database.
  • The application has no backend service, no analytics, and no telemetry.

4. Sharing and disclosure

The application does not share, transfer, sell, rent, or otherwise disclose Google user data to any third party. There are no advertisers, partners, or sub-processors. Data is disclosed only if required to comply with applicable law.

5. Limited Use disclosure

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Accordingly, Google user data is not used to:

  • Develop, improve, or train generalized artificial intelligence or machine-learning models
  • Serve advertisements, including personalized or retargeted advertising
  • Determine creditworthiness or for lending purposes
  • Be sold to third parties, or transferred to any party for the purposes above

Human review of this data does not occur. No one other than the account owner has access to it.

6. Data retention and deletion

  • Local credential files are retained until the owner deletes them. Deleting the file immediately ends the application's ability to access the account.
  • The owner may revoke the application's access at any time at myaccount.google.com/permissions. Revoking access invalidates the stored credentials.
  • Because calendar data is not retained on any external system, there is no server-side copy to delete.

7. Security

Credentials are stored only on the owner's local machine and are never transmitted except directly to Google's own OAuth and Calendar API endpoints over HTTPS. Access to the owner's computer is protected by the operating system's account security.

8. Children's privacy

The application is not directed at children and is not made available to any user other than its owner.

9. Changes to this policy

If this policy changes, the revised version will be posted at this URL with an updated date.
