hermes-calendar

A private, single-user automation for one person's own Google Calendar.

What this is

hermes-calendar is a personal-use software application that connects a local automation agent — running entirely on the owner's own computer — to the owner's own Google Calendar account.

It is not a product, service, or public offering. It is not distributed, and it has exactly one user: the person who owns both the software and the Google account it connects to. There is no sign-up, no other accounts, and no other users.

What it does

  • Creates calendar events and reminders at the owner's request
  • Reads existing events to check availability and avoid conflicts
  • Updates and deletes events the owner asks it to change

Google API scope requested

https://www.googleapis.com/auth/calendar — read and write access to the authorizing account's own calendars. This scope is used only to perform the actions listed above. No other Google data is requested or accessed.

How your data is handled

  • Calendar data is used only to carry out actions the account owner explicitly requests.
  • OAuth credentials are stored locally, on the owner's own machine. Google user data is not transmitted to, stored on, or processed by any third-party server.
  • No data is sold, shared, transferred, or disclosed to any third party.
  • No advertising, profiling, analytics, or machine-learning training uses your data.
